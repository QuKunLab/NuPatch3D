# 3D Cell Segmentation Benchmark

Code for running, evaluating, and analyzing 3D cell segmentation methods.

- **[segmentation_scripts](./segmentation_scripts/):** Run segmentation methods with default parameters; refer to each method’s project page for setup and required files.
- **[metrics](./metrics/):** Evaluate segmentation predictions against ground truth using instance, voxel, and boundary metrics.
- **[descriptors](./descriptors/):** Extract cell shape, density, and intensity descriptors from label masks and microscopy images.
- **[plot](./plot/):** Visualize method performance, comprehensive rankings, and correlations between segmentation metrics and image descriptors.
